# Vortex UI Add-on Changelog

## 2026.11.0

Initial release of Vortex UI, a configurable Home Assistant dashboard for wall displays and everyday use.

- Run as a standalone Docker application or install as a Home Assistant add-on.
- Build dashboards from views, sections, and configurable tiles.
- Connect to Home Assistant for live entity states and controls.
