# Vortex UI Add-on Changelog

## 2026.11.2

- Added an offline demo mode with a sample dashboard, mock entities, and simulated service calls, so Vortex UI can be explored without a Home Assistant connection.
- Added configurable detail columns (1–4) to the power summary.
- Expanded theme customization for UI colors and corner radii; added the Aurora, Graphite, and Porcelain themes.
- Improved theme-aware controls and modal contrast.
- Fixed dashboard resize controls remaining visible while a modal is open.
- Updated the documentation and manual with power and weather details.

## 2026.11.1

- Fixed Docker image builds by aligning dependencies with the project's SvelteKit and ESLint versions.

## 2026.11.0

Initial release of Vortex UI, a configurable Home Assistant dashboard for wall displays and everyday use.

- Run as a standalone Docker application or install as a Home Assistant add-on.
- Build dashboards from views, sections, and configurable tiles.
- Connect to Home Assistant for live entity states and controls.

## v2026.6.0

- Initial Vortex UI Home Assistant add-on release.
